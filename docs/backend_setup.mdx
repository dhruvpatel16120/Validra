## 🚀 Quick Setup (Automated)

Validra includes automated environment setup scripts inside the `backend/` directory.

### Windows (PowerShell)

```powershell
cd backend
.\setup.ps1
```

### Windows (CMD)

```cmd
cd backend
setup.bat
```

### Linux / macOS

```bash
cd backend
chmod +x setup.sh
./setup.sh
```

---

## 🛠️ Manual Setup

If you prefer to perform each setup step manually:

### 1. Navigate to Backend Directory

```bash
cd backend
```

### 2. Create Virtual Environment

```bash
python -m venv .venv
```

### 3. Activate Virtual Environment

- **Windows (PowerShell):** `.venv\Scripts\Activate.ps1`
- **Windows (CMD):** `.venv\Scripts\activate.bat`
- **Linux / macOS:** `source .venv/bin/activate`

### 4. Configure Environment Variables

```bash
cp .env.example .env
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 🏃 Running the Backend Server

Start the live-reloading development server:

```bash
uvicorn app.main:app --reload
```

The FastAPI server will be available at:

- **API Base URL:** `http://127.0.0.1:8000`
- **Swagger Interactive Docs:** `http://127.0.0.1:8000/docs`
- **ReDoc Interactive Docs:** `http://127.0.0.1:8000/redoc`
- **Health Check Endpoint:** `http://127.0.0.1:8000/health`
